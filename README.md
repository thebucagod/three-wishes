# Три желания — сайт кафе

Обычный статический сайт из трёх файлов. Сборка не нужна — откройте `index.html` в браузере.

| Файл | За что отвечает |
|---|---|
| `index.html` | Разметка: заголовки, тексты, картинки, ссылки, контакты, отзывы, FAQ |
| `style.css`  | Внешний вид: цвета, шрифты, отступы, адаптив под телефон |
| `script.js`  | Поведение: меню с вкладками, окно «Состав», FAQ, мобильное меню, форма |

## Что где править
- **Тексты, контакты, отзывы, вопросы** — в `index.html`. Секции подписаны комментариями `<!-- ===== ОТЗЫВЫ ===== -->`.
  Новый вопрос в FAQ — скопируйте целиком блок `<div class="faq-item card">…</div>`.
- **Цвета сайта** — в самом начале `style.css`, блок `:root`. Поменяли цвет там — он изменился везде.
- **Размеры, отступы, шрифты** — `style.css`, блоки пронумерованы по секциям страницы (оглавление в начале файла).
- **Блюда** (название, вес, цена, состав, фото) — массив `DISHES` в начале `script.js`.
  Карточки в `index.html` не пишутся руками: их строит скрипт из этого списка.
- **Фото блюда** — положите файл в папку `img/` и впишите путь в поле `img` (например `"img/pie.jpg"`).
  Пока поле пустое, показывается цветная заглушка с эмодзи.

## Картинки
Сейчас 6 картинок (2 на главной и 4 основных блюда) подгружаются с cdn.poehali.dev — они могут пропасть.
Один раз запустите `python download_images.py`: картинки скачаются в `img/`, ссылки заменятся на локальные.
Фото десертов и напитков в сохранённом коде не было — добавьте свои.

## Форма бронирования
Демо: проверяет поля и показывает «Заявка отправлена!», но никуда ничего не отправляет.
Чтобы заявки приходили, нужен сервис приёма форм или свой сервер (место в `script.js` помечено комментарием).

## Выложить на GitHub Pages
1. Создайте репозиторий на github.com, загрузите содержимое этой папки (`index.html` — в корне).
2. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.
